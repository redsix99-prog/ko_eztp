雪岳山・束草 旅行ガイド：2泊3日コース・名物料理・主な見どころ

東海と奇岩絶壁、紅葉の地

江原道の東海岸にある雪岳山は、鋭い岩峰と深い渓谷で知られる国立公園です。隣の束草は海と山を一緒に楽しめる港町で、登山、海辺の散歩、市場グルメを1〜2日で体験できます。

ひと目でわかる

  • ソウルから: 高速バスで約2時間30分〜3時間（交通状況による）
  • おすすめ日程: 1泊2日
  • ベストシーズン: 紅葉は10月上旬〜中旬。雪の積もる冬景色も人気
  • 移動: 束草の市内バス・タクシー。雪岳洞まではバスで移動

雪岳山・束草の主な見どころ

雪岳山国立公園

1970年に国立公園に指定された韓国を代表する山です。最高峰の大青峰は1,708mで、紅葉が国内で最も早く色づくと言われ、秋は特に混雑します。ロープウェイや短い登山道でも奇岩の景色を十分楽しめます。

  • 交通・移動: ソウルの東ソウルターミナルから束草行きの高速バスで約2時間30分〜3時間。束草市外バスターミナルから市内バス7番・7-1番で雪岳山ソゴンウォンまで約30〜40分です。
  • おすすめコース: ソゴンウォン → 神興寺 → ケーブルカーで権金城の展望 → 束草市内で夕食。紅葉の10月は週末の交通と駐車がとても混むので、早めに出発してください。
  • 地元の人が通うお店: 설악산 입구 산채비빔밥·두부 식당가 — ソゴンウォンの入口には山菜ビビンバや豆腐料理の食堂が並んでいます。山を下りたあとの温かい食事にぴったりです。 地図で見る ↗

蔚山岩

標高約873mの巨大な岩峰で、雪岳山の外縁を屏風のように囲んでいます。数百段の鉄製階段を登ると、頂上から束草市街と東海が一望できます。時間がかかるので早めに出発し、天気を確認しましょう。

  • 交通・移動: 束草市外バスターミナルから7番・7-1番バスで雪岳山ソゴンウォンまで行き、そこから歩いて出発します（蔚山岩まで片道約3.8km）。
  • おすすめコース: ソゴンウォン → 神興寺 → 揺れ岩 → 蔚山岩の頂上。往復約4〜5時間で、最後に長い鉄の階段が続きます。日没前に下山してください。
  • 地元の人が通うお店: 속초관광수산시장 닭강정 (Chicken Gangjeong) — 下山後は束草の観光水産市場でタッカンジョン（甘辛い韓国風唐揚げ）を持ち帰るのが、地元の人にも旅行者にも定番のコースです。天気の確認は必須です。 地図で見る ↗

新興寺・揺れ岩

雪岳洞の入口にある新興寺には、大きな青銅の座仏「統一大仏」があります。少し登ると、押すと揺れると言われる揺れ岩があります。緩やかな登りで、気軽に歩けるコースです。

  • 交通・移動: 束草市外バスターミナルから7番・7-1番バスで雪岳山ソゴンウォン（約30〜40分）。ソゴンウォンから神興寺までは平坦に近い道で、徒歩約20〜30分です。
  • おすすめコース: ソゴンウォン → 神興寺（統一大仏） → 揺れ岩（往復約1〜1.5時間） → 下山後は束草で食事。体力が足りなければ神興寺まででも十分です。
  • 地元の人が通うお店: 소공원 입구 산채비빔밥 식당가 — 神興寺は千年以上の歴史を持つ寺なので、境内では静かにし、服装も整えてください。入口の食堂街で山菜ビビンバやどんぐりゼリーをどうぞ。 地図で見る ↗

洛山寺

東海に面した崖の上にある寺で、海を向いて立つ海水観音像と義湘台が有名です。2005年の大規模な山火事の後に復元され、日の出の名所としても知られています。

  • 交通・移動: 束草市外バスターミナルから襄陽方面の市内バス・直行バスで約30分（洛山寺入口）。バス番号と時刻表は地図アプリで確認してください。
  • おすすめコース: 洛山寺 → 義湘台 → 紅蓮庵（岩の上の庵） → 洛山ビーチを散策 → 食堂街でムルフェ。
  • 地元の人が通うお店: 낙산해변 물회 식당가 (Naksan Beach) — 東海が一望できる寺なので、日の出や夕暮れどきが特におすすめです。寺なので境内では静かにし、洛山ビーチのムルフェの店で涼しく食事をどうぞ。 地図で見る ↗

アバイ村・ケッペ

朝鮮戦争の時に咸鏡道から避難してきた人々が定着した村です。青草湖を渡る「ケッペ」は鉄のロープを手で引いて進む独特の船で、束草旅行の体験のひとつです。名物のアバイスンデも味わえます。

  • 交通・移動: 束草市外・高速バスターミナルからタクシーで約5〜10分、市内バスでも行けます。ゲッペ（渡し舟）の船着場が村の入口です。
  • おすすめコース: 束草観光水産市場 → ゲッペ（綱を引いて渡る小舟）で青草湖を渡りアバイ村へ → 瀛金亭の夕日 → 束草ビーチ。どれも市内から近いです。
  • 地元の人が通うお店: 아바이마을 아바이순대·오징어순대 식당가 — 朝鮮戦争のときに北から南へ来た避難民が作った村で、アバイスンデ（韓国風の腸詰め）とイカスンデが有名です。ゲッペは乗ること自体が楽しいので、一度乗ってみてください。 地図で見る ↗

束草観光水産市場

束草で最も大きな伝統市場で、タッカンジョン（甘辛チキン）、オジンオスンデ（イカの詰め物蒸し）、新鮮な海産物が有名です。タッカンジョンの店は行列ができることが多いので、時間に余裕を持ちましょう。

  • 交通・移動: 束草市外バスターミナルから市内バスやタクシーで約5〜10分。中央洞一帯の市場の入口は大通りからすぐ見えます。
  • おすすめコース: 市場でタッカンジョンとイカスンデ → ゲッペでアバイ村へ → 瀛金亭の夕日 → 束草ビーチで締めくくり。半日で十分です。
  • 地元の人が通うお店: 만석닭강정 (Manseok Dakgangjeong) — 束草のタッカンジョンは甘辛い韓国式の唐揚げで、旅行者のお土産にも人気です。有名店はテイクアウトの行列が長いので、午前か遅めの時間がおすすめです。 地図で見る ↗
広告

束草で食べたいグルメ

タッカンジョン

カリッと揚げた鶏肉を甘辛いタレに絡めた、束草観光水産市場（中央市場）の名物です。冷めてもおいしいので、箱で買って宿や帰りのバスで食べる人が多いです。

  • マンソク・タッカンジョン中央市場本店 만석닭강정 중앙시장 본점 — 束草のタッカンジョンを全国に広めた店で、市場内の本店前にはいつも行列ができます。マイルドと辛口から選べます。
  • チュンアン・タッカンジョン 중앙닭강정 — 同じ市場にあるもう一つの人気店で、2軒で買って食べ比べる旅行者も多いです。

アバイスンデ・イカスンデ

咸鏡道出身の避難民が故郷の味を再現したアバイスンデは、豚の腸にもち米・血・野菜を詰めた大ぶりの腸詰め。イカスンデはイカの胴に具を詰めて蒸し、卵の衣をつけて焼いたものです。

  • タンチョン食堂 단천식당 — アバイ村のスンデ横丁で最も古く有名な店の一つで、スンデ・スンデクッパ・ゆで豚のセットが人気。ケッペに乗って渡ったついでに寄れます。
  • シンダシン 신다신 — アバイ村の中にあるスンデ専門店で、アバイスンデとイカスンデを一度に味わえます。マッコリにもよく合います。

ムルフェ・ズワイガニ

ムルフェは新鮮な刺身と野菜に冷たい甘酸っぱいスープを注いだ東海岸の名物で、麺やご飯を入れて食事にします。冬から春はズワイガニ・ベニズワイガニが旬で、港の食堂で蒸して食べられます。

  • ボンポ・モグリチプ 봉포머구리집 — 束草のムルフェといえば必ず名前が挙がる海辺の食堂で、海鮮たっぷりのムルフェが看板メニュー。夏の週末は待ち時間が長めです。
  • チョンチョス・ムルフェ本店 청초수물회 본점 — 青草湖の近くにある大型のムルフェ専門店で、席数が多く家族やグループでも利用しやすいです。

ハクサピョンのスンドゥブ

雪岳山へ向かう途中にあるハクサピョンのスンドゥブ村では、毎日手作りのおぼろ豆腐を出しています。白いままヤンニョム醤油で食べたり、ピリ辛のスンドゥブチゲで味わったり。朝早くから開く店が多く、登山前の食事にぴったりです。

  • キム・ヨンエおばあさんのスンドゥブ本店 김영애할머니순두부 본점 — 1965年創業のハクサピョンを代表するスンドゥブ店で、メニューはスンドゥブ定食の一品のみ。おからチゲとおかずが付きます。朝7時ごろから営業。
  • ハクサピョン・スンドゥブ村 학사평 순두부마을 — スンドゥブの店が一つの町に集まっているので、有名店が混んでいたら近くの別の店を選んでも十分おいしいです。

おすすめ日程

  1. 1日目: 束草に到着 → 新興寺・揺れ岩 → 蔚山岩またはロープウェイ
  2. 2日目: アバイ村・ケッペ → 束草観光水産市場 → 洛山寺

旅のヒント

  • 紅葉の時期や週末は雪岳洞へ向かう道がとても混むので、朝早く出発しましょう。
  • ロープウェイや一部の登山道は強風や雪で運休・立入禁止になることがあります。
  • 蔚山岩は往復で数時間かかるので、体力と日没時間を考えましょう。
  • 山は天気の変化が早いので、上着と水を用意し、登山靴を履きましょう。

営業時間・料金・休業日は変わることがあります。訪問前に公式サイトや地図アプリで最新情報をご確認ください。
