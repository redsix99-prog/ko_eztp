Korea Easy Trip が自ら調べてまとめた、ソウルと近郊の観光スポット30か所です。各ページでアクセスとおすすめコース、地元の人が通う店やカフェ、看板メニューと価格帯、ドラマ・映画のロケ情報、四季の風景を確認できます。

洗練されたソウル

南山、ロッテワールドタワー、漢江の夜景まで。昼より夜に輝く街に出会いましょう。

  • Nソウルタワー（南山） — 南山の頂上にあり、ソウル全体を見渡せます。ケーブルカーや循環バスのほか、時間があれば南山の遊歩道を歩いて登るのもおすすめです。
  • ロッテワールドタワー — 高さ555mの超高層ビルで、上層の展望台「ソウルスカイ」から漢江と都心を一望できます。天気や大気の状態で眺めが大きく変わります。
  • 盤浦大橋・漢江の夜景 — 漢江の夜景を手軽に楽しむなら盤浦漢江公園がおすすめです。盤浦大橋の「月光レインボー噴水」が照明と重なって川面に虹を描きます。運営時間は季節で変わるのでソウル市…
  • 纛島漢江公園 — 聖水洞に近い漢江公園で、川風を感じながら座って過ごせます。夕暮れには対岸の灯りがともり、「漢江ラーメン」や出前チキンのピクニック文化も体験できます。
  • 駱山公園 — 漢陽都城の城郭に沿って歩く散策路で、夕焼けと夜景が特に美しいと言われます。近くの梨花壁画村とあわせて回れます。
  • 汝矣島 — 国会議事堂と金融街がある汝矣島は、夜になるとまったく違う顔を見せます。ザ・現代ソウルでショッピングし、漢江公園で自転車やピクニックを楽しんでいるうちに日が暮れ…

洗練されたソウルの楽しみ方

  • 南山ケーブルカー: 明洞駅3番出口 → 徒歩約15分。大人往復1万5千ウォン、10:00〜23:00。
  • ソウルスカイの眺め: 日没1時間前に上って夕焼けと夜景を一度に。大人3万ウォン台。
  • 漢江遊覧船の夜景: 汝矣島船着場（汝矣ナル駅）から出発。一般乗船券1万〜2万ウォン台。
  • トゥクソムのドローンショー＆ピクニック: 2026年のドローンショーは10月31日で終了、ピクニックは一年中楽しめます。7号線紫陽駅のすぐ前。
  • 駱山公園 × ケデホン: ルミとジヌの夜の場面の舞台。恵化駅から出発して日没に合わせて。

K-ビューティー・ショッピング

明洞・聖水・弘大のオリーブヤングから予算別おすすめ、売れ筋コスメ、半日ショッピングルートまで一度に。

  • 明洞 — 外国人旅行者に最も人気のソウルのショッピング街で、コスメやファッションの店が集まります。夕方には屋台が並び、さらに活気づきます。
  • 弘大エリア — 美術大学の周辺から生まれた若者の街で、バスキング、インディーズ音楽のクラブ、個性的なお店が揃います。日が暮れるとネオンと屋台スナックで一段と賑わいます。
  • 聖水洞 — 古い工場や倉庫を改装したカフェ、セレクトショップ、ポップアップストアが集まる街です。週末は混むので午前中のスタートがおすすめです。
  • 東大門デザインプラザ（DDP） — 曲線的な外観が特徴の建物で、展示やファッションイベントが頻繁に開かれます。夜はライトアップされ、周辺の東大門ファッション街とあわせて楽しめます。
  • コエックス・ピョルマダン図書館 — 三成洞の大型複合モールで、高い書棚が並ぶピョルマダン図書館が撮影スポットです。ショッピング、展示、水族館を一か所で楽しめます。
  • 江南駅 — 地下鉄2号線江南駅の交差点は、大型オリーブヤングやブランドの旗艦店が集まるソウル最大級のショッピング・ビューティー街の一つです。駅直結の地下商店街や裏路地の飲…

地域別オリーブヤング主要店舗

  • ソウル明洞・オリーブヤング明洞タウン: 外国人客向けのグローバル特化店舗（2023年11月リニューアル）。
  • ソウル聖水・オリーブヤングN聖水: 5フロア・約1,400坪で国内最大の店舗。売上の約70%が外国人客です。
  • ソウル弘大: 店舗数が最も多い商圏。2フロアの弘大L7店など複数店舗が徒歩圏内にあります。
  • ソウル江南・オリーブヤング セントラル江南タウン: 外国人客向けのパーソナルショッパーサービスがあります。
  • 釜山・西面／光復洞（南浦）／海雲台: 釜山旅行の3大中心商圏に店舗が集まっています。地図で最寄りの店を探しましょう。
  • 済州・済州市蓮洞・老衡（新済州）: 済州は外国人ショッピング需要が最も急増した地域。空港に近い新済州に店舗が集まっています。

予算別ショッピングガイド

  • 1万ウォン以下: シートマスク（1枚1〜3千ウォン台）、リップバーム、ミニサイズ、こんにゃくゼリーなどのおやつ。友達へのお土産にまとめ買い。
  • 1万〜3万ウォン: 日焼け止め、トナーパッド、セラム、クレンザー、リップティント。外国人旅行者が一番多く買う価格帯です。
  • 3万ウォン以上: アンプル・スキンブースター、企画セット、美容機器、コラーゲンなどのインナービューティー。セール期間（オルヨンセール）が狙い目。

外国人によく売れるコスメ

  • 日焼け止め：朝鮮美女 澄んだ米の日焼け止め: 白浮きやテカりが少なく保湿クリームのように塗りやすいのが人気の理由。
  • セラム：トリデン ダイブインセラム: ヒアルロン酸の保湿セラムとして根強く推薦されています。
  • シートマスク：メディヒール: 種類が多く安いので、まとめ買いやお土産に人気。
  • スキンブースター：VTリードルショット、メディキューブPDRN: SNSで話題の製品群。初めてなら低濃度から試しましょう。
  • おやつ：ディライトプロジェクト ベーグルチップ、こんにゃくゼリー: 日本・東南アジアの旅行者に特に人気のヘルシーおやつ。

半日ショッピングルート

  • 明洞コース: 明洞駅 → オリーブヤング明洞タウン → 明洞の屋台グルメ → 新世界免税店明洞店11階K-WAVEゾーン（K-POPグッズ）。
  • 聖水コース: ソウルの森駅 → KWANGYA@SEOUL（SMグッズ）→ オリーブヤングN聖水 → 練武場キルのポップアップ → カフェで休憩。
  • 弘大コース: 弘大入口駅 → 弘大のオリーブヤング → 弘大の歩きたい通りでバスキング鑑賞 → 延南洞の京義線森の道を散歩。

ショッピングのコツ

  • パスポートを持参: 即時還付（タックスフリー）対応店が多く、パスポートを見せると会計時にその場で税金が戻ります。条件は店舗で確認を。
  • ダイソー・ムシンサも: 2026年の外国人ショッピングはオリーブヤング・ダイソー・ムシンサに集中。ダイソーは安いコスメ・日用品、ムシンサは韓国ファッションブランドが強み。

ソウル近郊の自然

地下鉄で行ける北漢山から、紅葉・城郭・島の日帰り旅行まで。

  • 北漢山 — ソウル北部にある国立公園で、地下鉄とバスで行ける都心の山です。最高峰の白雲台（約836m）からはソウル市街が一望でき、体力に合わせて選べる緩やかな道もあります。
  • 道峰山 — 北漢山とつながる岩山で、尖った岩峰が連なる景色が印象的です。地下鉄道峰山駅から登山口へ直行できますが、岩場は靴と天気を必ず確認してください。
  • 南漢山城 — ソウルから1時間ほどの山城で、2014年にユネスコ世界遺産に登録されました。城郭沿いの道は緩やかで、紅葉の季節は特に人気です。
  • 冠岳山 — ソウル南部の岩山で、頂上付近の恋主台が有名です。登りがきついので登山経験のある方向きで、複数の方向から登れます。
  • 南怡島 — 北漢江に浮かぶ小さな島で、メタセコイアの並木道と四季の景色が人気の日帰り旅行先です。韓国ドラマのロケ地として知られ、外国人観光客も多く訪れます。
  • 朝の静けさの庭園（アチムゴヨ樹木園） — 京畿道加平にある韓国式の庭園で、季節ごとに異なる花や木が楽しめます。冬の光の祭りで知られるので、運営日程を確認してお出かけください。

登山用品のレンタル：ソウル都心登山観光センター

  • 北漢山センター（月曜休み）: 牛耳新設線北漢山牛耳駅から徒歩5分。白雲台コースの登山口に近いです。
  • 北岳山センター（火曜休み）: 鍾路区三清路88。漢陽都城の城郭道や青瓦台の裏山コースに。雨具やキャンプチェアなども借りられます。
  • 冠岳山センター（水曜休み）: 冠岳区新林路23、新林線冠岳山駅構内地下1階。電車を降りてすぐ装備を借りて登山を始められます。

季節別の持ち物

  • 春・秋: 寒暖差が大きいので薄手の上着を重ね着。紅葉シーズンの週末は朝早く出発を。
  • 夏: 水1リットル以上、帽子、虫よけ。梅雨（6月末〜7月）は渓谷の水が急に増えることがあります。
  • 冬: アイゼン、手袋、保温ボトル。冬の日没は午後5時〜5時半ごろなので、遅くとも午後3時には下山開始を。
  • 登山道の規制を確認: 山火事警戒期間（春・秋）や悪天候時は一部の登山道が規制されます。国立公園公団のサイトで確認を。

伝統文化

宮殿と韓屋、世界遺産の城郭まで。韓国の歴史を歩いて出会います。

  • 景福宮 — 1395年に朝鮮王朝の正宮として建てられました。光化門から勤政殿、慶会楼へ続く軸線を歩くと、都の壮大さが伝わります。韓服着用の特典などは公式案内でご確認くださ…
  • 北村韓屋村 — 景福宮と昌徳宮の間の丘に韓屋が集まる街です。今も住民が暮らしているので静かに歩きましょう。瓦屋根と街並みを見下ろす景色が定番の撮影ポイントです。
  • 昌徳宮 — ユネスコ世界遺産に登録された宮殿で、自然の地形を生かした建物配置が特徴です。後苑（秘苑）は時間制の観覧なので事前にご確認ください。
  • 仁寺洞 — 伝統工芸品店、茶屋、ギャラリーが並ぶ通りです。ッサムジキルを散策して、伝統茶や韓菓で一息つきましょう。
  • 徳寿宮 — 市庁前にあって行きやすい宮殿で、伝統建築と洋風建築が並びます。隣接する石垣の道は散歩コースとして人気です。
  • 水原華城 — 朝鮮の正祖の時代に築かれた城郭で、ユネスコ世界遺産です。ソウルから電車で行けて日帰り旅行に人気で、城壁を一周すると2〜3時間はあっという間です。

作品の舞台と実際の場所

  • 北村 ↔ KPop Demon Hunters「Free」屋根の場面、ソンジェ背負って走れの井戸: 住宅地のため訪問時間制限あり（月〜土10〜17時）。
  • 駱山公園城郭道 ↔ ルミとジヌの夜の場面: 日没直後が一番映画のよう。
  • Nソウルタワー ↔ 最後の公演: 作中の公演会場は架空の空間です。
  • 明洞 ↔ サジャボーイズ「Soda Pop」初ステージ: オリーブヤング明洞タウンと一緒にどうぞ。
  • ソウルスカイ ↔ HUNTR/Xの宿舎: 実際は117階以上の展望台です。
  • 景福宮 ↔ ソンジェ背負って走れ、婚礼大捷: 韓服を着ると無料で入場できます。
  • 仁寺洞 ↔ 映画「仁寺洞スキャンダル」: 骨董店や画廊の路地を歩いてみましょう。

半日コース（地図）

  • 宮殿・韓屋コース（約4〜5時間）: 景福宮駅で韓服レンタル → 景福宮（無料入場、守門将交代式）→ 北村韓屋村 → 仁寺洞サムジキル → 益善洞で夕食。
  • ケデホン聖地巡り（約4時間、午後出発）: 北村韓屋村 → 昌徳宮前の敦化門路 → 恵化駅 → 梨花洞壁画村 → 駱山公園城郭道で夕日と夜景。

韓服体験

  • 宮殿の無料入場: 伝統韓服（チョゴリ＋チマまたはパジ）を着ると景福宮・昌徳宮など4大宮と宗廟に無料で入れます。一部のフュージョン韓服は認められないことがあります。
  • 料金と場所: 景福宮駅3・4番出口周辺と北村入口にレンタル店が集まっています。数時間で1万5千〜2万5千ウォン台が多く、ヘアセット・小物は追加料金。
  • 韓服男 景福宮店: 景福宮近くの代表的なレンタル店の一つで、伝統韓服とテーマ韓服を選べます。予約サイトで事前予約するとお得なことが多いです。

K-POPグッズショップ

  • KWANGYA@SEOUL（聖水）: SMエンターテインメント公式フラッグシップストア。アクロソウルフォレストDタワー地下1階、ソウルの森駅と直結。アルバム・ペンライト・トレカなど。
  • 新世界免税店明洞店 K-WAVEゾーン: 11階のK-POP特化売り場でBTS・BLACKPINK・BIGBANG・NCTなどのグッズを販売。免税店なのでパスポートと出国情報が必要です。
  • 明洞のK-POPグッズ店: 明洞の通りにはアルバムやグッズを売る店が多く、客のほとんどが外国人。正規品かどうかと価格を比べましょう。
  • ソウルマイソウルショップ: ソウル市公式のお土産店。明洞観光情報センター店、世宗文化会館店などでソウルグッズが買えます。

グルメと市場

広蔵市場のピンデトックから鍾路3街の屋台、南大門のタチウオ煮付けまで。市場の写真をタップすると店・メニュー・価格帯をご案内します。

  • 広蔵市場 — 1905年に開設されたと伝わるソウルを代表する伝統市場です。ピンデトック、マヤクキンパ、ユッケが有名で、昼前後は行列ができます。
  • 鍾路3街の老舗食堂街 — 鍾路3街一帯は、昔ながらの食堂や屋台横丁、楽器店街の楽園商街が集まるソウルを代表する老舗の街です。クッパ、焼き魚、マッコリなど常連客に長く愛される店が多く、メ…
  • 乙支路の路地 — 印刷所や照明店が並ぶ古い路地の間に、老舗の食堂やビアホールが隠れていて「ヒップジロ」とも呼ばれます。色あせた看板と細い路地そのものが見どころで、夕方にはノガリ…
  • 通仁市場 — 景福宮の西、西村にある小さな市場です。昔の銅銭でおかずを選ぶお弁当カフェが話題になりました。
  • 南大門市場 — 衣類、雑貨、台所用品まで何でも揃うソウル最大級の伝統市場です。カルグクス横丁や太刀魚の煮付け横丁も地元の人に親しまれています。
  • 鷺梁津水産市場 — 鷺梁津駅のすぐそばにある水産市場で、好きな活魚や海鮮を自分で選んで2階の食堂でそのまま味わえます。未明の競売も見ものですが、日中訪れても十分に見て回って食事が…

市場の楽しみ方

  • 現金も少し用意: ほとんどカードが使えますが、屋台や小さな店は現金のみのことも。1万ウォン札数枚で十分です。
  • 少しずついろいろ: 1軒でお腹を満たすより2〜3軒で分けて食べるのが市場の楽しみ方。1人1品を求める店もあるので確認を。
